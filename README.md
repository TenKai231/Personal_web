# 🌐 Rama Ferdiansyah – Personal Website

Welcome to my personal portfolio website repository.

This project represents my journey in **Data Engineering and Web Development**, showcasing my skills, experience, and technical growth through a modern and responsive website.

---

## 🚀 About This Project

This website was built from scratch using clean and semantic HTML, modern CSS, and vanilla JavaScript.

It is designed to:

- Present my professional profile
- Highlight technical competencies
- Showcase selected projects
- Provide a direct contact channel

The goal of this project is to demonstrate not only technical knowledge but also attention to design, structure, and usability.

---

## 🛠 Tech Stack

- **HTML5** – Semantic and structured markup
- **CSS3** – Responsive layout with modern styling
- **JavaScript (Vanilla JS)** – Interactive elements
- **Font Awesome** – Icons
- **Git & GitHub** – Version control
